# 视觉系统与组件规范

## 设计方向

已确认：浅色技术手册。整体像个人维护的高质量工程笔记：暖灰底、白色正文、青绿色强调、克制的边框。保留阅读空间；练习页密度可以更高。无大幅营销横幅、渐变背景、卡通插画和多色统计大屏。

静态图见 [visuals](visuals/README.md)，尺寸与行为以本文及 05 为准。图中使用占位代码说明区域，不是网站实现代码。

## 字体与排版

中文采用系统无衬线字体栈，优先苹方/微软雅黑；拉丁字符随系统 sans-serif；代码使用本地等宽字体，不依赖外部字体 CDN。

| 角色 | 字号/行高 | 字重 |
| --- | --- | --- |
| 页面标题 | 30 / 42 px，手机 26 / 36 | 650—700 |
| 正文文章标题 | 32 / 44 px | 700 |
| 二级标题 | 22 / 32 px | 650 |
| 三级标题 | 18 / 28 px | 600 |
| 正文 | 16 / 28 px，可调 18 / 32 | 400 |
| 导航/按钮/表格 | 14 / 22 px | 400—600 |
| 注释/元数据 | 13 / 20 px | 400 |
| 代码 | 13 / 22 px，可独立缩放 | 400 |

不使用小于 12 px 的有效信息。文章正文最大宽度 760 px，默认 720 px，段间 16 px；H2 前 40 px 后 16 px。中文段落不做两端强制拉伸。代码不在标识符中间自动断行，允许块内横向滚动并可切换软换行。

## 网格与响应式

- 基础间距：4、8、12、16、24、32、48、64 px。
- 1440 px 参考视口：顶栏 64，无左栏，主区左右 padding 32，内容最大宽 1200。
- 文章阅读区单栏居中，正文最大 760，不设右提纲。
- 768—1279：同一条顶栏，正文两侧 24。
- <768：顶栏折成品牌、分区、搜索三行，两侧 16，单列，触控目标至少 44×44。
- 工作台 ≥1200：题面 38%，编辑区 62%；题面最小 360，编辑区最小 520，底部结果区高 240；小屏用题目/代码/结果 tab。
- 200% 缩放走实际可用宽度断点，禁止固定整页横向滚动；代码/表格自身可滚动。

## 基础组件

| 组件 | 尺寸/形态 | 状态与行为 |
| --- | --- | --- |
| 主按钮 | 高 40，手机 44；左右 16；圆角 8 | 默认、hover、focus、busy、disabled |
| 次按钮 | 白底有边框，与主按钮等高 | 删除用 danger 文字，不与主操作抢视觉 |
| 搜索框 | 桌面宽 320—420，高 40 | 有真实 label、清空按钮、加载/无结果 |
| Tag | 高 24，圆角 6 | 纯信息标签不能假装按钮 |
| 知识行 | 最小高 76，标题+摘要+元信息 | 整行链接不包裹收藏按钮，操作区分开 |
| 面板 | 圆角 12，边框 1，padding 24 | 只在浮层使用轻阴影，常规卡片不漂浮 |
| 进度条 | 高 6，配文本 x/y | 不是交互控件，不用颜色作为唯一信息 |
| 提示块 | 左侧图标，浅背景，padding 16 | 区分结论、反例、边界、待核验 |
| 代码块 | 标题栏标语言/复制，内容 16 padding | 复制不改变页面滚动；失败可选取 |
| 折叠区 | 标题行高 ≥44 | Enter/Space 展开，提供 expanded 状态 |
| 评分按钮 | 四个等宽，桌面单行，手机 2×2 | 文案+下次间隔，答案展示后才可评分 |
| Toast | 底部靠右，手机底部居中 | 普通成功 3 秒；错误保留至关闭，有重试 |
| Dialog | 桌面宽 480，手机宽屏减 32 | 焦点锁定、Esc 关闭、关闭后返回触发点 |
| Drawer | 桌面宽 400，手机接近全屏 | 标题、关闭、独立滚动、背景不可交互 |

## 交互动效

hover 120 ms、抽屉 180 ms；尊重减少动态效果设置，切换用瞬时状态。骨架仅在确实加载时出现，避免闪烁。评分完成不播放大型庆祝动画，以队列进度变化为反馈。

## 无障碍

目标 WCAG 2.2 AA：常规文字至少 4.5:1，大字 3:1，关键控件与焦点边界至少 3:1；实际实现逐组件验证，不以色表代替检测。[WCAG 官方标准](https://www.w3.org/TR/WCAG22/)。

全站提供跳到正文；导航标记当前位置；弹层可键盘关闭；运行结果与保存错误用状态区域播报；标题层级连续；编辑器提供纯文本输入模式与 Tab 焦点逃离说明。阅读内容不能依赖 hover 才能获得。表格有标题及列头，图示有文字等价解释。

快捷键：Cmd/Ctrl+K 搜索；Esc 关浮层；工作台 Cmd/Ctrl+Enter 运行（可关闭）。复习页答案展开后 1—4 评分，仅焦点不在输入框/编辑器时生效。普通空格继续用于滚动，不能全局劫持。

## 文案样例

首页：「今天，巩固一点。」；空收藏：「把值得反复看的内容留在这里。」；保存失败：「这次更改还没保存。请重试，或先复制内容。」；通过：「当前代码已通过全部用例。」；待核验：「这篇内容需要重新核对工具版本。」；不使用指责性文案或学习焦虑倒计时。
