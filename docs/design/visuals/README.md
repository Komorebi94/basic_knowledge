## 复现要求

- 不将示例个人数字写死到网站。
- 图中不包含所有异常弹窗，必须实现 05 的异常矩阵。
- 主操作、正文宽度、三栏/双栏/单列转换是核心；不要用任意现成模板替换。
- 实际页面支持字号调整、键盘焦点、读屏和内容增高；不能用截图做页面。
- PNG 已检查文字与布局可辨认；静态图不能证明真实网页响应式、可访问性或保存行为正确。
