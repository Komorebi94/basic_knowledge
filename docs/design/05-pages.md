# 页面级设计规格

每页必须同时实现默认、空、加载、错误与窄屏状态。本文件和 04 构成页面还原依据，静态图提供视觉参照。

## S01 总览

**目的**：立即决定今天做什么。布局：左栏 + 顶栏 + 主内容两列。首屏从上至下：日期与标题、今日回顾主卡、继续学习、辅列学习概况。下半屏是三条学习路径与近期内容变化。

- 主卡：到期总量、今天计划量、预计耗时（卡片数×1分钟，仅估算）、「开始回顾」主按钮；有未完成会话时改为「继续回顾」并显示 x/y。
- 继续学习：最近打开的有效文章/最近编辑的题目，最多 3 项，各自明确「继续阅读/继续练习」。不把刚搜索过的内容算作在学。
- 概况：已读文章、独立通过题、今日已回顾，三个不同口径的小指标；点击进入对应筛选。
- 学习路径：基础与运行机制、工程质量、AI 协作实践，各显示下一篇和条目数。
- 近期变化：最近核验且有实质更新的 3 条，显示变化说明；只改排版不进入此模块。
- 首次使用：主卡改「从一次小复习开始」，可选一条路径；个人统计全部为 0；已发布内容数量可以展示。
- 存储故障：顶部常驻提示并指向恢复/导出，不阻断文章阅读；写操作按 11 降级。
- 手机顺序：标题 → 回顾 → 继续学习 → 三个小统计 → 路径 → 更新。

## S02 知识地图

标题「知识地图」，摘要「从语言机制到工程决策，按主题建立完整理解」。顶部筛选和搜索，主体展示 16 个专题分组，每组摘要、核心概念、已读/已发布计数、进入专题按钮。默认列表/紧凑卡片混合，拒绝占满屏幕的节点连线图。

先显示通用基础，再框架、工程与架构。手机单列可折叠分组；桌面两列专题卡。筛选为零时提供「清除筛选」。全部内容加载失败显示重试，不能显示成“没有知识”。

## S03 专题目录

顶部显示专题名、目标能力、建议前置知识、阅读统计。中部用「核心 → 进阶 → 拓展」分段；每行标题、两行以内摘要、阅读时间、已读状态、卡片进度与收藏。

右侧可显示关联练习 3 条和建议学习顺序，无右栏时收为底部区块。前置知识只提示，不锁定阅读。待写条目放底部「后续内容」折叠区，计数不算已发布。

## S04 知识阅读

**阅读区单栏**：保留全站侧栏与返回专题链接，正文居中、最大宽度 760px。按用户 2026-09-30 的最新要求，不显示右提纲、移动端「本页目录」、来源与核验区或个人笔记区。旧阅读设计图为历史草图，以本节和 D14 为准。

正文顺序：返回专题 → 标题与摘要 → 预计阅读时间 → 从具体问题开始 → 机制推导 → 代码与预期输出 → 逐步解释 → 工程应用与边界。内容按理解路径展开，不强制套用“核心结论/主动回忆”小标题，不用短提纲代替教程。

代码与解释可交替出现，示意图必须有文字说明；复制与软换行保持可用。章节 ID 保留，外部深链接定位并聚焦对应标题。阅读区不插入未交付的收藏、评分或复习按钮。

笔记集中到「我的积累」：选择对应文章后编辑，自动保存、冲突比较与切页保护仍适用。切换对应文章或分类也属于离开编辑上下文，未保存输入不能悄悄丢失。笔记持久化键、备份和恢复规则不变。

来源、版本、核验日期仍作为内部内容维护数据保留，不自动渲染成阅读模块。影响结论的环境条件直接写在相关正文或例子中，避免没有环境说明的绝对结论。AI 单元同样使用此阅读壳。

手机：正文单列、两侧 16px；不显示额外的页内目录与笔记工具栏。代码可在自身区域横向滚动或切换软换行，整页不得横向溢出。

## S05 动手练习列表

标题「动手练习」，说明「先独立实现，再用用例验证边界」。顶部主题、难度、完成证据、运行环境筛选。列表行含标题、能力点、建议分钟、环境标识、完成证据、收藏。

推荐首组：防抖、Promise.all、并发控制、深拷贝、事件订阅、LRU、请求竞态；完整顺序见 08。首版列表只露出已可使用的题，不给 P1 题展示虚假的运行入口。

点击行进入 S06；行内“继续”恢复草稿，“重新尝试”进入工作台后再确认，列表不直接清空代码。

## S06 练习工作台

专注布局：顶部仅返回列表、标题、难度、保存状态、收藏；左侧题面，右侧代码与结果。参考 [工作台设计图](visuals/03-practice.svg)。

左侧 tabs「题目 / 提示 / 解析 / 历史」。题面固定包括能力目标、输入输出、语义约定、样例、限制、边界、关联知识。提示 1 是方向、提示 2 是结构、提示 3 是关键细节；点开时显示本次将记为参考完成。解析不自动展开。

右侧：语言（P0 固定 JavaScript）、代码输入、重置骨架、运行按钮、停止按钮。下方 tabs「测试结果 / 控制台」。结果逐条展示用例名、通过/失败、可读 expected/actual、错误信息；对象输出限长，可展开或复制。不提供隐藏测试噱头，所有要求与用例目的公开。

运行期间按钮显示「运行中」并可停止；加载运行环境与执行用例区分。加载失败可以重试，代码可继续编辑/下载。运行结束聚焦结果摘要但不移走正在输入的焦点；通过后提供「写下复盘」与「回顾相关知识」。

「重置代码」显示确认，会删除当前草稿但保留尝试历史。「开始新尝试」也确认，初始化骨架并重置本次提示记录；先保存旧草稿到历史快照。

手机/平板窄屏：题目、代码、结果三个顶层 tabs，不同时挤压双栏。固定下方运行条；软键盘出现时保持当前光标可见，不要求手机承担完整 IDE 体验。

## S07 AI 工程

顶部标题与说明「让 AI 参与实现，也让过程可检查」。主区六个入口：基础概念、交付任务、审阅与验证、约束与权限、工具与协议、AI 应用工程；「近期变化」为独立小区域。

首屏横向流程为 需求 → 上下文 → 计划 → 实现 → 验证 → 审阅 → 交付，每步可进入对应文章。下面是三个场景：新增功能、排查缺陷、审阅改动；点击进入工作模板。

侧栏显示「本月核验」和待核验数量，不显示模型排行榜。不把厂商发布当成普遍结论，不给未核验文章打“最新”标签。

## S08 AI 阅读/模板/案例

共享 S04 单栏阅读壳；工具版本与适用条件写入相关正文，核验日期和来源保留于内部维护记录。模板模式增加「复制模板」和未填写变量清单，复制的是带占位提示的纯文本。用户自行填入工作项目资料，本站不上传。

审阅案例模式分四步：问题说明 → 待审改动片段 → 我的判断 → 参考检查结果。默认折叠参考结果；用户可写风险、证据、建议，保存为本地笔记。自评分为「找出问题 / 证据不足 / 需要再看」，首版不调用模型自动判卷，也不混用练习独立通过指标。

近期变化文章需有“发生了什么、影响哪些做法、是否适用于我的工作、如何复现验证、来源与日期”；界面标签是「近期变化」或「待核验」，不用永久的“最新”。

## S09 复习计划

顶部到期数量、今日已完成、设置入口。主体：继续未完成会话卡、到期/新卡两个计数、每日目标、开始按钮。下方按专题列出已订阅卡片，可暂停/恢复；暂停不删除记录。

默认计划 20 张，其中最多 5 张新卡；可选 10/20/30。可从特定专题开始一次专项回顾。额外复习入口明确不影响默认队列选择规则，但评分仍影响这张卡的下次日期。

无到期但有新卡时「学习新卡」；均无时引导加入知识，不显示不可解释的空白。超额到期显示“还有 x 张待回顾，可分批进行”。

## S10 复习会话

顶部返回、专题、进度 x/y；中央问题卡（宽不超 760）；答案隐藏时只有问题、可选「我的回答」文本框和「显示要点」主按钮。展开后呈现结论、依据、易错点、原文链接；底部四个评分按钮标下次间隔。

评分即时持久化并进入下一张，支持撤销最近一项评分；进入下一题已编辑答案后撤销先询问是否保留该答题草稿。退出不丢评分与当前回答，再进入恢复。最后一张完成后显示本次张数、忘记/不稳的数量、返回原知识建议；不展示“能力超过 x% 用户”。

手机 2×2 评分按钮，底部安全区加留白。评分按钮在答案未展开前不显示，快捷键也无效。见 [移动设计图](visuals/04-mobile-review.svg)。

## S11 我的积累

顶部 tabs：笔记、收藏、薄弱项、学习记录。每个 tab 有本地搜索和类型过滤。笔记按最近修改排序；收藏按加入时间；薄弱项按 03；历史按日期聚合评分与有效练习尝试，运行异常单独标识。

条目不存在时显示原标题和「原内容已归档」，可继续复制/编辑笔记、取消收藏。删除只在笔记详情中执行，列表避免误触。手机 tabs 可横向滚动，有可见选中状态。

## S12 设置与数据

分区：阅读（16/18px）、复习（10/20/30、时区）、快捷键、数据管理、内容版本。数据管理展示笔记/草稿/评分事件数、上次主动导出时间、导出 JSON、导入备份、清除个人数据。

导入先校验再显示预览，P0 只支持全量替换，明确说明替换哪些记录，并强制提供当前数据备份下载完成步骤后才可确认替换。损坏文件显示具体字段与行/路径，不泄露原始敏感正文。

清除数据需输入「清除个人数据」确认；仅清本应用命名空间，不能清整站或其他应用存储。页面布局采用表单和说明，不使用系统设置式多层嵌套。

## S13 搜索与 S14 找不到内容

搜索弹层由全局按钮或快捷键打开；焦点在输入框，方向键选择、Enter 进入、Esc 关闭返回来源。完整结果页保留查询与筛选，显示结果总数和命中摘要。

找不到内容页：明确标题、原路径、返回首页、搜索相近内容；若有旧 slug 映射自动跳转而非显示错误。不存在的本地复习 session 提供回到复习计划，不伪造一场历史会话。

## 全局异常

| 事件 | 展示 | 恢复路径 |
| --- | --- | --- |
| 内容加载失败 | 正文区域错误卡 | 重试/回目录 |
| 个人数据库不可用 | 顶部常驻提示 | 临时阅读、复制草稿、重试 |
| 索引加载失败 | 搜索框旁说明 | 重建/重试，仍可目录浏览 |
| 外部来源打不开 | 保留来源标题和日期 | 复制链接、稍后访问 |
| 新内容版本可用 | 轻提示 | 保存后刷新，不能中断编辑 |
| 程序未知错误 | 局部错误面板 | 重试、导出可读取个人数据 |
