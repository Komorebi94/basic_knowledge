用户已确认全站知识与 AI 文章采用深入教程标准（D15），并确认浅色技术手册方向，并要求详细教程及专注正文的单栏阅读区（D14）；旧阅读图中的右提纲与笔记区已废止。其余默认决策、可更换选项及影响范围见 [交接记录](15-handoff.md)。不需要把尚未确定的框架、品牌名或部署服务当成设计阻塞。

## 阅读与冲突处理

1. 先读 01、02、04、05 和设计图，理解产品与外观。
2. 再读 03、06、11、12，理解真实状态与技术边界。
3. 内容制作读 07—10 和 examples；开发排期读 13—15。
4. 优先级：用户后续明确要求 > 15 中登记的新版决策 > 功能/数据/交互规范 > 静态设计图。设计图的数字是示例数据，不是业务常量。
5. 术语：P0 是首版必须交付；P1 是完整产品的后续增强；P2 是可选探索。内容的「核心/进阶/拓展」是学习深度，和交付优先级无关。
