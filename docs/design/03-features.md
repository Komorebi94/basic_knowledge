# 功能规格与状态规则

## 阅读与掌握分离

打开正文后置为「在读」，仅用户点击「标记已读」才变「已读」。滚动到底不算已读，阅读时长不算掌握。允许撤回为在读。卡片熟练状态由评分规则推导；练习完成证据由通过结果与辅助记录推导。不得将三者压成一个百分比。

文章标题下显示专题标识与预计阅读时间；核验记录留在内部内容数据，不在正文插入目录、来源核验、笔记或未交付操作。详见 S04 与 D14。

## 练习状态

草稿状态：空白 → 编辑中 → 保存中 → 已保存/保存失败。

运行状态：未运行 → 准备中 → 运行中 → 全部通过/部分失败/运行异常/超时/已停止/环境不可用。任一运行完成后可以重新运行；正在运行时禁止启动第二轮，但允许停止与继续编辑。

运行使用点击时的代码快照。运行中编辑不改变该轮结果。结果绑定 codeRevision 和题目 revision；代码再变更后旧结果标注「对应上一版代码」，不能沿用绿色通过作为当前状态。

学习证据：未尝试、练习中、参考完成、独立通过。提示任一层、参考解析或答案被本次尝试打开，则该次通过只能标「参考完成」。自我声明用过外部帮助也进入参考完成。新尝试可从初始骨架开始并重置该次辅助记录，历史不清除。系统不声称能检测外部复制。

知识学习卡的自评不因为练习通过而自动升档。练习完成后显示「是否回顾关联知识」，不隐式替用户评分。

## 笔记规则

笔记统一在「我的积累」中选择文章并编辑，文章正文不内嵌编辑器。

- 同一用户、同一内容、同一章节最多一份可编辑笔记；无章节表示整篇笔记。
- 500 ms 自动保存，最多 20,000 字符；字符计数常显，超限阻止继续提交并保留当前输入用于复制。
- 内容以纯文本存储，Markdown 预览禁用原始 HTML、脚本、远程嵌入；外链仅允许 http/https。
- 删除笔记需确认，确认框包含标题；删除前可复制，P0 不做回收站。
- 保存失败时保留内存稿、展示重试与复制；跳转站内页面先询问是否放弃未保存更改，浏览器关闭仅尽力提示。
- 跨标签页冲突保留本地未提交版本，不采用悄悄覆盖，见 11。

## 薄弱项

来源一：最近一次卡片评分为「忘记了/不太稳」。来源二：练习最近一次有效完成的运行有失败，或最近一次完成证据为参考完成且没有后续独立通过。来源三：用户手动「加入补强」。

同一内容合并原因标签，按手动标记优先、最近失败时间倒序。通过后只清除练习自动原因，卡片原因必须靠之后卡片评分改变；手动原因由用户取消。超时、环境不可用不自动解释为知识薄弱，但保留运行历史。

## 统计口径

- 已读数量：published 内容中 reading.status 为 read 的文章数；归档内容另列，不计分母。
- 独立通过：当前题目 revision 上至少一次无辅助且全部通过的题数；新 revision 后旧结果标「旧版已通过，待验证」。
- 本周回顾：时区内本周一 00:00 至现在，未撤销的卡片评分事件数；另给唯一卡片数。
- 今日完成：当日未撤销评分涉及的唯一卡片数，同一张补练不重复累计。
- 阅读/练习时间不做首版 KPI，避免后台挂页虚增。预计耗时属于内容元数据，不是假装测量所得。

## 内容更新与空状态

尚未发布的内容只可在独立「后续计划」折叠区显示标题，不可点击进空文章。首次进入显示三条入门路径与零状态说明，绝不填充虚构个人记录。没有到期卡片时显示「今天的回顾已完成」以及学习新知识入口；队列过多时显示剩余数量并允许手动追加，不自动延长会话。

## P1/P2 的展示纪律

未实现能力不显示可点击的假按钮。首版不展示 AI 聊天输入框、云同步图标或无效的深色切换。后续功能在文档保留，在产品里只有真正可用后才出现。
