# K09 作者示例复现

在仓库根目录完成锁文件安装后运行 `npm run verify:k09`。本次工具版本：Node 22.22.3、Rolldown 1.2.11（Vite 的锁定依赖）、TypeScript 6.0.3。报告逐例保存代码摘要、输出及运行环境；浏览器示例由隔离 Chrome 空白页执行，Node 示例独立 ES 模块进程执行并核对标准输出、错误输出及超时。

`scripts/lib/tooling-fixture.mjs` 是完整可读的作者辅助源码：

- `bundle(modules, options)` 用虚拟模块插件构建固定入口，返回真实 chunk/map，不下载或安装依赖，结束后关闭构建。
- `withFiles(files, action)` 在系统临时目录写入固定作者文件，拒绝越界路径，执行后清理。不是用户文件执行接口。
- `runChunks(output, action)` 将 chunk 写入独立临时 ESM 包，用 Node 真正导入入口；map 实验独立查询构建返回的映射。

Node 代码块可保存为仓库根目录的 `.mjs` 文件后运行，保持辅助模块相对 import 路径。每个例子独立运行，不依赖前一个例子的状态。K09-05 HTTP 实验只在 127.0.0.1 的随机端口监听，结束后关闭；它检查真实响应而不证明浏览器或 CDN 的缓存命中。临时包不执行安装脚本。

调度、受影响图、产物配对、灰度与 loader 示例明确为教学模型。真实工具实验与模型证据分别注明；本验证没有调用生产、CI、监控、远程缓存或云账户。工具版本升级之后必须重新核对生成关系和映射，不能沿用旧报告。
