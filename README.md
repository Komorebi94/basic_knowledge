# 前端知识库

面向前端开发者的系统复习知识库。以长期有效的 JavaScript、浏览器、框架和工程原理为主，新特性与 AI 专题为补充。

```bash
pnpm install
pnpm dev
```

模块：JavaScript、浏览器、TypeScript、CSS、React、Vue、工程化、手写题、AI。

卡片圆点表示重要程度，不代表技术先进程度。复习时建议先完成高频核心条目，再看深入和扩展内容。

## 常用命令

```bash
pnpm dev           # 启动开发环境
pnpm format        # 格式化项目
pnpm format:check  # 检查格式
pnpm lint          # 代码检查
pnpm build         # 类型检查并构建
pnpm check         # 依次检查格式、lint 和构建
```
